1. 数据加载与坐标系

页面加载时向后端 POST /elevation_viewer_data 拉取 JSON，存入全局 data。

关键字段

  • data.points_display — 点云在 Three.js 显示坐标系中的坐标 (N×3)
  • data.points_aligned — 点云在重力对齐坐标系中的坐标 (N×3)，Y 轴朝上
  • data.colors — 点云 RGB 颜色 (N×3, uint8)
  • data.R_align — 3×3 重力对齐旋转矩阵
  • data.T_display — 4×4 世界→显示坐标变换矩阵
  • data.dem — DEM 网格：grid_res, x_min/max, z_min/max, elev[i][j], has_data[i][j]
  • data.cameras — 每帧相机光心（aligned 和 display 两套坐标）

坐标变换函数

// aligned → display（用于所有几何体的最终定位）
function alignedToDisplay(ax, ay, az) {
  world = R_align^T @ [ax, ay, az]
  display = T_display @ [world, 1]
}

// display → aligned（用于选区反投影）
function displayToAligned(dx, dy, dz) {
  world = T_display^-1 @ [dx, dy, dz, 1]   // T_display 为刚体变换，逆 = R^T | -R^T t
  aligned = R_align @ world
}

2. 点云渲染

函数：buildScene()

  • 用 points_display 作为 Three.js position attribute
  • 同时把 points_aligned 存为额外 attribute alignedPos，供 tooltip 读取
  • 备份原始颜色到 originalColors，选区高亮时覆盖，清除时还原
  • 渲染完成后用 computeBoundingSphere() 自动定位相机

3. Reference Plane（参考平面）

函数：buildRefPlane()，在 populateSidebar() 时调用一次。

高度计算

遍历 DEM 所有格元，取 has_data == false（最近邻填充格元）的高程均值作为参考平面 Y：

refY = mean( elev[i][j]  for all (i,j) where has_data[i][j] == false )
// fallback：若 DEM 全部有数据，取网格中心格元高程

设计意图：has_data=false 的格元是地面点稀疏的边缘区域，其最近邻填充值代表远场平坦地面，比有密集点的区域更稳定。

几何构建

  • 范围：DEM 的 (X, Z) 范围向外扩展 30%（pad = max(xSpan, zSpan) * 0.3）
  • 面片：固定高度 refY 的水平矩形，半透明青色（opacity 0.10）
  • 网格线：10×10 格线叠加（opacity 0.30）
  • 所有顶点坐标经 alignedToDisplay() 转换后写入 Three.js

作为高度零点

refYAligned 存为全局变量，tooltip 显示的 Y 值 = (点的 aligned Y − refYAligned) × scaleFactor，即相对参考平面的高度。

与体积计算的关系

体积计算不使用 refYAligned，而是用选区内 DEM 高程的最小值作为基准（见第 9 节）。两者独立。

4. 坐标轴

函数：buildAxes(origin, size)，锚定在参考平面中心。

  • X/Y/Z 三轴方向由 alignedToDisplay(1,0,0) 等计算，确保轴方向与重力对齐坐标系一致
  • 轴长 = sceneBSRadius * 0.6（场景包围球半径的 60%）
  • 用 CSS2DRenderer 渲染 X/Y/Z 文字标签，始终面向相机

5. DEM Mesh（Fill Holes）

函数：buildDEMMesh()，勾选 "Fill Holes & Show DEM Mesh" 时触发。同时构建两个网格：

Filled Mesh（默认显示）

对 DEM 高程做迭代空洞填充，最多 20 轮，每轮用 8 邻域均值填充空洞格元：

for pass in range(20):
    for each (i,j) where filledMask[i][j] == false:
        neighbors = 8-connected cells where filledMask == true
        if neighbors exist:
            filled[i][j] = mean(neighbors)
            filledMask[i][j] = true
    if no cell changed: break

颜色编码：灰色 = 原始有数据格元，橙色 = 填充格元。

三角化：每个 (i,j) 格元拆成两个三角形，全部格元均参与（含填充区域）。

Original Mesh（对比用，默认隐藏）

只对四角均有真实数据的格元建面，空洞区域直接跳过，保留原始 DEM 的孔洞形态：

if hasData[i][j] && hasData[i][j+1] && hasData[i+1][j] && hasData[i+1][j+1]:
    build quad

颜色编码：灰色 = 有数据，深灰 = 无数据（不建面，仅占位顶点）。

6. Filled / Original 对比切换

按钮 "Showing: Filled ⇄" 切换 demMesh.visible 与 demMeshOrig.visible，两个 Mesh 始终存在于 scene 中，只切换可见性。

"Hide original point cloud" 复选框直接控制 pointCloud.visible，方便单独查看 DEM 网格。

7. Hover Tooltip（悬停坐标）

函数：onMouseMove()

  • 用 Three.js Raycaster 对 pointCloud 做射线检测，取最近命中点的索引
  • 从 alignedPos attribute 读取该点的重力对齐坐标
  • X、Z 直接乘 scaleFactor；Y 先减去 refYAligned 再乘 scaleFactor，得到相对参考平面的高度
  • 选区模式（selectMode == true）时禁用 tooltip

8. Region Selection（区域选择）

函数链：startSelectMode → onSelMouseDown/Move/Up → computeSelection

绘制阶段

在 overlay canvas（2D）上实时绘制选区形状（矩形 / 圆 / 椭圆），纯视觉反馈，不涉及三维。

反投影阶段（computeSelection）

鼠标抬起后，将屏幕矩形的四个角点反投影到三维地面平面：

// 1. 确定地面高度：取 points_aligned 中 Y 坐标最低 10% 的中位数
groundY_aligned = percentile(points_aligned[:, 1], 10)

// 2. 将 groundY_aligned 转换为 display 空间的 Y 值（用于平面方程）
groundY_display = T_display @ R_align^T @ [cx_dem, groundY_aligned, cz_dem]

// 3. 对屏幕四角各发射一条射线，与 display 空间中 Y=groundY_display 的水平面求交
corner_display = ray.intersectPlane( Plane(normal=[0,1,0], constant=-groundY_display) )

// 4. 将交点从 display 转回 aligned XZ
corner_aligned = displayToAligned(corner_display)

点选取

在 aligned XZ 平面上按形状判断每个点是否在选区内：

  • 矩形：AABB 测试
  • 圆：dx²+dz² ≤ r²（取 rxA, rzA 中较小值为半径）
  • 椭圆：(dx/rx)²+(dz/rz)² ≤ 1

选中点颜色改为黄色（1.0, 1.0, 0.0），清除时从 originalColors 还原。

9. Volume 体积计算

在 computeSelection() 末尾执行，基于 DEM 格元而非点云。

// 只统计 has_data == true 且在选区内的格元
elevInRegion = [ elev[i][j]  for (i,j) in region if hasData[i][j] ]

// 基准高程 = 选区内最低格元高程
minElev = min(elevInRegion)

// 体积 = Σ (elev[i][j] - minElev) × cellArea × scaleFactor
cellArea = cellW × cellH × scaleFactor²
volume   = Σ (e - minElev) × cellArea × scaleFactor

注意：基准是选区内 DEM 的最低点，不是 reference plane。scaleFactor 对面积贡献平方、对高度贡献一次，共三次方，单位为 m³。

空洞格元（has_data == false）不参与体积计算，即使在选区内也跳过。

10. Camera Extrinsics

函数：buildCameraTable() / buildCameraSpheres()

  • 表格显示每帧相机光心的 aligned 坐标 × scaleFactor（单位 m）
  • 勾选 "Show cameras in 3D" 时，用 center_display 坐标在场景中渲染彩色小球（半径 0.008）
  • 重力来源（trajectory / ground_mask / cloud_ransac）显示在表格上方

11. Scale Calibration

查看器提供两种可切换模式：保留原有的手填统一 scaleFactor，或通过已知长宽高的语义标定物拟合局部地面平面，得到水平 s_h 与竖直 s_v 两个尺度。

  • 手动模式：X/Y/Z 都使用 scaleFactor，与旧流程兼容。
  • 局部平面模式：X、Z 和面积使用 s_h；Y、高程、分类阈值和深度使用 s_v；体积使用 s_h² × s_v。
  • 后端会拒绝不完整标定物、缺少地面 mask 或可用点不足的帧，并在前端显示保留帧和尺度 rMAD。
  • 不影响三维场景的几何渲染；只影响量纲、测量与高程导出。

1. 系统概述与研究背景

本系统针对无人机航拍视频或多视角图像序列，实现从单目视频输入到三维点云重建、语义分割、地形高程建模及体积估算的完整自动化流程。系统融合了两个前沿深度学习模型：VGGT（Visual Geometry Grounded Transformer）负责无需显式 SfM 的端到端三维重建，YOLOe（You Only Look Once — Efficient）负责开放词汇语义分割，二者通过微服务架构协同工作。

传统三维重建流程依赖 Structure-from-Motion（SfM）与多视图立体（MVS）的两阶段管线，计算开销大且对特征点稀疏场景鲁棒性差。VGGT 以 Transformer 架构直接从图像序列回归深度图与相机位姿，突破了传统方法的局限。在语义层面，YOLOe 支持文本提示、视觉提示及无提示三种分割模式，可灵活适配不同应用场景下的目标类别定义。

系统的核心应用场景包括：无人机航拍地形测量、建筑物体积估算、地面障碍物检测与三维定位，以及基于重力对齐坐标系的相对高程分析。

3. 三维重建模块（VGGT）

3.1 模型原理与推理流程

VGGT（Visual Geometry Grounded Transformer）是一种端到端的多视图三维重建模型，以图像序列为输入，直接回归每帧的深度图、世界坐标点图及相机位姿，无需传统 SfM 的特征匹配与光束法平差（Bundle Adjustment）步骤。

推理时，图像序列经预处理后以批次形式送入模型：

images = load_and_preprocess_images(image_names)  # → (S, 3, H, W)
with torch.no_grad():
    with torch.cuda.amp.autocast(dtype=bfloat16):
        predictions = model(images)

模型输出的 predictions 字典包含以下关键张量：

键名形状含义
depth(S, H, W)每帧深度图（相机坐标系 Z 值）
depth_conf(S, H, W)深度置信度，范围 [0, 1]
world_points(S, H, W, 3)直接回归的世界坐标点图
world_points_conf(S, H, W)点图置信度
extrinsic(S, 3, 4)世界→相机变换矩阵 [R | t]
intrinsic(S, 3)相机内参 (fx, fy, cx, cy 的紧凑表示)
world_points_from_depth(S, H, W, 3)由深度图反投影得到的世界坐标点

3.2 点云坐标计算方法

系统提供两种点云来源，可通过 prediction_mode 参数切换：

模式一：深度图反投影（Depthmap and Camera Branch）

对于帧 s 中像素 (u, v)，设深度值为 d，相机内参为 (fx, fy, cx, cy)，外参为 [R | t]，则世界坐标计算如下：

(1) Xcam = [ (u − cx) / fx · d, (v − cy) / fy · d, d ]T
(2) Xworld = RT (Xcam − t)

其中 R 为 3×3 旋转矩阵，t 为 3×1 平移向量，均来自 VGGT 预测的外参矩阵 extrinsic[s]。

模式二：直接点图（Pointmap Branch）

VGGT 亦可直接回归每像素的世界坐标 world_points[s, v, u, :]，无需显式反投影，适用于深度估计不稳定的场景。

置信度过滤

两种模式均支持基于置信度的点云过滤，过滤条件为：

(3) keep(s, v, u) = finite(Xworld) ∧ conf(s, v, u) ≥ τ · max(conf)

其中 τ 为用户设定的置信度阈值百分比（默认 50%），finite 检查排除 NaN 与 Inf 值。

3.3 相机位姿估计

VGGT 输出的外参矩阵 extrinsic[s] 为世界坐标系到相机坐标系的变换 [Rs | ts]，形状为 (3, 4)。相机光心在世界坐标系中的位置为：

(4) Cs = −RsT ts

相机轨迹 {Cs}s=1..S 构成的点集用于后续重力方向估计（见第 5 节）。

4. 语义分割模块（YOLOe）

4.1 分割模式与推理策略

YOLOe 服务支持三种分割模式，适配不同的先验知识条件：

模式API 端点输入适用场景
文本提示分割POST /segment类别名称列表已知目标类别，如"ground, building"
视觉提示分割POST /segment_visual参考图像 + 边界框无法用文字描述的目标外观
无提示分割POST /segment_promptfree无（自动检测）未知场景，自动发现主要类别

无提示模式采用两阶段策略：第一阶段遍历所有帧统计各类别出现频次，第二阶段选取频次最高的 K 个类别（默认 K=10）重新推理生成掩码，以 RAM 标签词表（约 4,585 类）作为候选集。

4.2 掩码提取与坐标映射

YOLOe 推理输出的掩码张量 masks.data 形状为 (N, mH, mW)，其中 N 为检测实例数，(mH, mW) 为模型内部分辨率（含 letterbox 填充）。还原至原始图像分辨率的步骤如下：

步骤 1：计算 letterbox 缩放比例与填充量：

(5) scale = min(mH / Horig, mW / Worig)
(6) padh = (mH − Horig · scale) / 2, padw = (mW − Worig · scale) / 2

步骤 2：裁剪有效区域并双线性插值至原始分辨率：

(7) maskcrop = mask[round(padh) : round(padh + Horig·scale), round(padw) : round(padw + Worig·scale)]
(8) maskfinal = resize(maskcrop, (Worig, Horig), INTER_LINEAR)

最终输出的 semantic_masks.npz 中，每帧掩码为形状 (H, W) 的 uint8 数组，像素值 0 表示背景，1–9 表示对应语义类别 ID。该掩码在后续 VGGT 重建阶段用于标记地面点，指导重力方向估计与高程平面拟合。

5. 重力方向估计与坐标系对齐

VGGT 的世界坐标系遵循 OpenCV 相机约定（X 轴向右，Y 轴向下，Z 轴向前），不保证 Y 轴与重力方向对齐。为使后续高程分析具有物理意义，系统通过 gravity_alignment.py 模块估计重力方向，并将点云旋转至重力对齐坐标系（Y 轴指向上方）。

5.1 三级级联估计策略

系统采用三级级联策略，按可靠性从高到低依次尝试，一旦某级成功则停止：

级别 1（主方法）：轨迹平面法 — 利用相机运动轨迹的 PCA 估计地面法向量
级别 2（备选）：地面掩码 RANSAC — 利用 YOLOe 标记的地面点拟合平面
级别 3（兜底）：全点云 RANSAC — 对全部点云进行无先验平面拟合

若级别 1 与级别 2 均可用，系统还会进行一致性校验：若两者估计的法向量夹角超过 10°，则发出警告但仍采用轨迹平面结果。

5.2 轨迹平面法（主方法）

无人机等航拍设备的飞行轨迹近似位于与地面平行的平面内，该平面的法向量即为重力方向的近似估计。

步骤 1：由外参矩阵计算各帧相机光心：

(9) Cs = −RsT ts, s = 1, …, S

步骤 2：对相机光心集合进行零均值化后执行 SVD 分解：

(10) X = {Cs − mean(C)}, X = U Σ VT

步骤 3：计算各主成分的特征值并检验轨迹退化性：

(11) λi = σi2 / max(S−1, 1), ratio = λ2 / λ1

若 ratio < 0.1（轨迹近似为直线，退化情形），则放弃轨迹平面法，转入级别 2。

步骤 4：取方差最小的特征向量（SVD 最后一行）作为平面法向量：

(12) ntraj = VT[−1, :]

步骤 5：法向量方向校正 — 确保大多数点云位于法向量负侧（相机在地面上方）：

(13) ngrav = sign(−median((P − anchor) · ntraj)) · ntraj

5.3 地面掩码 RANSAC 法

当 YOLOe 提供了地面语义掩码时，从标记为地面的点中随机采样拟合平面。

RANSAC 迭代（迭代次数 400，内点距离阈值 0.03）：

  1. 随机采样 3 个地面点 p0, p1, p2
  2. 计算候选法向量：n = (p1−p0) × (p2−p0)，归一化
  3. 先验约束检验：|n · nprior| > cos(60°)（若先验可用）
  4. 计算所有地面点到候选平面的距离：
(14) di = |(Pi − p0) · n|
  1. 统计内点数 cnt = |{i : di < 0.03}|，保留内点最多的候选
  2. 对最优内点集执行 SVD 精化，得到更精确的法向量

置信度加权：若提供置信度图，则过滤掉置信度低于最大值 50% 的点，以提高拟合质量。

5.4 全点云 RANSAC 法

当地面掩码不可用时，对全部点云（最多随机采样 200,000 点）执行无先验约束的 RANSAC 平面拟合，算法流程与 5.3 节相同，但先验余弦阈值放宽至 0.6（若有先验）或 0.0（无先验）。

5.5 旋转矩阵计算

估得重力方向 ngrav 后，计算将其旋转至 [0, 1, 0]（Y 轴向上）的最短弧旋转矩阵：

(15) v = ngrav × [0,1,0], s = ‖v‖, c = ngrav · [0,1,0]
(16) Ralign = I + [v]× + [v]×2 · (1−c) / s2

其中 [v]× 为向量 v 的反对称矩阵（Rodrigues 公式）。当 ngrav 与 [0,1,0] 夹角接近 180° 时，选取与 ngrav 正交的任意轴执行 180° 旋转。

对齐后的点云与外参更新为：

(17) Paligned = Ralign Pworld
(18) R's = Rs RalignT, t's = ts

6. 地形平面拟合与数字高程模型

完成重力对齐后，Y 轴即为高程轴（Y 值越小表示越高，因 VGGT 原始坐标系 Y 向下）。elevation_plane.py 模块在对齐坐标系中拟合数字高程模型（Digital Elevation Model, DEM）。

6.1 地面点提取

地面点的选取策略依据是否存在语义掩码而分为两种：

有语义掩码时

计算所有语义标记地面点的 Y 坐标中位数，并在其 ±5% Y 值域范围内筛选：

(19) yrange = P98(y) − P2(y)
(20) tol = 0.05 · yrange
(21) G = { Pi ∈ ground_mask : |Pi,y − median(yground)| ≤ tol }

无语义掩码时

取 Y 坐标最低的 p% 点作为地面候选（默认 p=20）：

(22) G = { Pi : Pi,y ≤ Pp(y) }

6.2 DEM 网格插值

以地面点集 G 在 (X, Z) 平面上构建规则网格，插值得到高程值：

步骤 1：确定网格范围（含 5% 边界填充）：

(23) xmin' = xmin − 0.05·(xmax−xmin), xmax' = xmax + 0.05·(xmax−xmin)

步骤 2：生成均匀网格（默认分辨率 128×128）：

(24) ξi = linspace(xmin', xmax', Ngrid), ζj = linspace(zmin', zmax', Ngrid)

步骤 3：散点插值（优先线性，NaN 处回退最近邻）：

(25) elevlinear(ξ, ζ) = griddata({(Gi,x, Gi,z)}, Gi,y, (ξ, ζ), method="linear")
(26) elev(ξ, ζ) = elevlinear(ξ, ζ) if not NaN, else elevnearest(ξ, ζ)

6.3 网格化曲面重建

将 DEM 网格转换为三角网格（Triangulated Irregular Network, TIN）：

对每个网格单元 (i, j)，以四顶点 i00, i10, i01, i11 构建两个三角面片：

(27) F1 = (i00, i10, i01), F2 = (i10, i11, i01)

顶点坐标为 (ξi, elev(i,j), ζj)，颜色由高程值归一化后映射至 colormap（默认 terrain）：

(28) normij = clip((elevij − elevlo) / (elevhi − elevlo + ε), 0, 1)
(29) colorij = colormap(normij) × 255

最终网格以 GLB 格式导出，可与原始点云 GLB 合并为统一场景文件。

7. 体积计算方法

7.1 基于 DEM 的体积积分

系统构建的 DEM 为后续体积计算提供了完整的数学基础。对于目标物体（如土方堆、建筑物等），体积可通过以下方法计算：

方法一：DEM 差分积分（挖填方体积）

设参考基准面高程为 href（通常取地面 DEM 的中位数），目标区域内各网格单元的高程为 elev(i,j)，则超出基准面的体积为：

(30) V = Σ(i,j) ∈ Ω max(elev(i,j) − href, 0) · ΔX · ΔZ

其中 ΔX = (xmax' − xmin') / (Ngrid−1)，ΔZ = (zmax' − zmin') / (Ngrid−1) 为网格单元尺寸，Ω 为目标区域的网格索引集合（可由语义掩码投影确定）。

方法二：点云凸包体积

对于由语义分割提取的目标点云子集，可直接计算三维凸包（Convex Hull）体积作为目标体积的上界估计：

(31) Vhull = ConvexHull({Pi : semantic_id(Pi) = k}).volume

方法三：三角网格封闭体积

若目标点云可构成封闭三角网格，则利用散度定理（高斯公式）计算精确体积：

(32) V = (1/6) |Σf (v0 + v1 + v2) · (v1 − v0) × (v2 − v0)|

7.2 尺度因子与绝对单位

VGGT 输出的点云坐标为相对尺度（无量纲），需通过尺度因子 α 转换为绝对物理单位（如米）：

(33) Pmetric = α · Paligned
(34) Vmetric = α3 · Vrelative

尺度因子 α 可通过以下方式标定：

  • 已知距离标定：场景中存在已知尺寸的参照物（如标定板、建筑物层高）
  • GPS 轨迹标定：利用无人机 GPS 轨迹的实际飞行距离与重建轨迹长度之比
  • 用户手动输入：通过 Orchestrator UI 的 scale_factor 参数直接指定
注意：当前系统默认 scale_factor = 1.0，即输出为相对尺度。在进行绝对体积计算前，必须通过上述方法确定并设置正确的尺度因子。

8. 三维可视化与坐标变换

系统提供基于 Three.js 的交互式三维查看器，支持点云、相机轨迹与 DEM 网格的同步显示。为兼容 GLB 文件的 OpenGL 坐标约定，系统维护三套坐标系并提供相互转换：

坐标系约定用途
VGGT 世界系X 右，Y 下，Z 前（OpenCV）模型原始输出
重力对齐系X 右，Y 上，Z 前高程分析、体积计算
显示系（GLB）X 右，Y 上，Z 后（OpenGL）Three.js 渲染

从 VGGT 世界系到显示系的变换矩阵 Tdisplay 由以下步骤复合得到：

(35) Topengl = diag(1, −1, −1, 1) （Y、Z 轴翻转）
(36) Trot180y = Ry(180°) （绕 Y 轴旋转 180°）
(37) Tdisplay = E0−1 · Topengl · Trot180y

其中 E0 为第一帧相机外参的 4×4 齐次矩阵，用于将世界坐标系原点对齐至第一帧相机位置。

查看器数据接口（POST /elevation_viewer_data）同时返回三套坐标下的点云与相机数据，以及 128×128 分辨率的 DEM 网格，供前端按需渲染。

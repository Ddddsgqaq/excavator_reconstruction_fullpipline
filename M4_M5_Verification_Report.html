摘要 / Abstract

本报告记录 M4（坐标稳定）与 M5（持久融合 + 多 tile）在真实 NVIDIA RTX 5070 Ti 上的端到端验证结果。 使用含真实相机运动的航拍视频作为输入，M4 通过冻结锚点与轮间配准将跨轮 DEM 漂移从 0.0077 m 降至 0.0056 m； M5 通过全局融合累加器实现地形持续生长（11,770 → 25,666 cells），并成功发布 6 个独立 tile，变化检测收敛至每轮 4 个 tile。

测试 2 — M5 持久融合 + 多 tile / Persistent Fusion

PASS

使用 tools/verify_m5.py 验证全局融合累加器、多 tile 切分与变化检测在真实重建数据上的表现。

python tools/verify_m5.py dji_fly_20260511_161858_0_1778489356002_video.mp4 \ --seconds 50 --interval 6 --target-fps 1.0 --auto-scale --viz --viz-dir ./verify_m5_viz

结论 / Conclusions

  • M4 坐标稳定：冻结锚点 + 轮间配准在真机端到端跑通，数值上有效减小跨轮 DEM 漂移。
  • M5 持久融合：全局融合累加器 + 多 tile 切分 + 变化检测在真重建数据上真正工作；地形随视频持续生长并填充，成功发布多个 tile，变化检测收敛。
  • 尺度局限：绝对尺度仍任意（VGGT 固有），--auto-scale 仅为演示适配；真源接入需按真实米制标定。
  • 未覆盖项：接真 Unity 目视多 tile 拼接验证；MQTT 通道验证（缺 broker）。

复现要点 / Reproduction Notes

  • 必用有相机运动的航拍视频 + --target-fps 1.0。
  • M5 必加 --auto-scale，否则所有点挤进 1 格。
  • 两脚本已支持从任意目录运行（自动把 repo root 加进 sys.path）。

高程图平面拟合方案与路线总结

基于当前项目代码整理：gravity_alignment.py 负责重力/水平面方向估计， elevation_plane.py 负责 DEM 插值和 GLB 导出， vggt_service.py 与 elevation_viewer.html 提供接口和交互式查看。

1. 总体定位

当前项目中的“高程图平面拟合”不是把全部地形压成一个单一平面，而是分成两层：

层级 目的 实现位置
平面拟合 / PCA / RANSAC 估计场景中的重力方向，也就是把“向上”对齐到坐标系 +Y。 gravity_alignment.py
DEM 曲面拟合 在重力对齐后的水平 (X, Z) 平面上，对地面点的 Y 值做规则网格插值，得到数字高程模型。 elevation_plane.py、vggt_service.py:/elevation_viewer_data
代码里保留了 use_ransac 参数，但在 fit_elevation_to_glb 中已经标记为兼容旧接口，实际由重力估计级联流程替代。

2. 主流程路线

1. VGGT 重建 得到深度图、相机外参、世界点云与置信度，保存到 predictions.npz。
2. 可选 YOLOe 语义 若存在 semantic_masks，语义 ID 为 1 的点被视为地面候选来源。
3. 重力对齐 通过相机轨迹平面、地面 mask 平面或全点云 RANSAC 估计重力方向，并旋转点云。
4. DEM 插值 在对齐坐标中选地面点，用 griddata 在 (X,Z) 规则网格上插值 Y。
5. 输出与查看 生成彩色高程 mesh 的 GLB，并通过 Three.js viewer 展示 DEM、参考平面、体积选择。

3. 重力方向与平面拟合

VGGT 输出的世界坐标不保证和真实重力方向一致，因此系统先估计一个世界坐标中的“向上”单位向量 n_grav，再构造旋转矩阵 R_align，使：

R_align @ n_grav = [0, 1, 0]

应用后，点云坐标变为：

points_aligned = points_world @ R_align.T

此后 Y 被当作高程轴，(X, Z) 被当作水平平面。

3.1 级联估计策略

优先级 方法 数据来源 说明
1 主方法 相机轨迹平面 PCA extrinsic 推出的 camera centers 对相机中心做 SVD/PCA，取最小方差方向作为轨迹平面法向量。若轨迹近似直线，判定退化并跳过。
2 语义辅助 地面 mask RANSAC semantic_masks == 1 的 3D 点 当有地面语义时拟合地面平面。若轨迹法向已存在，则作为一致性检查或 fallback。
3 兜底 全点云 RANSAC 全部有效点云，最多采样 200,000 点 当轨迹和语义都不可用时使用。若有先验法向，会限制候选平面大致平行于先验。

3.2 轨迹法退化与一致性检查

轨迹 PCA 中计算前两个主方向方差比 eig[1] / eig[0]。若小于 TRAJ_DEGENERATE_RATIO = 0.1，说明相机运动近似一条线，无法可靠确定轨迹平面。

当轨迹法和地面 mask 法都可用时，系统计算两个法向夹角。若超过 GRAVITY_DISAGREE_DEG = 10°，会记录 warning，但当前策略仍优先使用轨迹法。

4. 地面候选点筛选

重力对齐后，系统在 _select_ground_aligned 中提取用于高程图插值的地面点。

有语义地面 mask

若存在 semantic_masks 且语义 ID 1 有足够点数，先取这些点作为地面集合。 为减少误分割和非地面物体影响，再按 Y 中位数附近的窄带过滤：

tol = 0.05 * (P98(Y_all) - P2(Y_all))
G = ground_mask_points where abs(Y - median(Y_ground)) <= tol

无语义 mask 或点数不足

使用高程百分位 fallback。默认取 Y 最低的 20% 点作为地面候选：

threshold = percentile(Y_aligned, ground_percentile)
G = points_aligned where Y <= threshold
这里的目标不是重新拟合一个地面斜平面，而是得到足够稳定的地面采样点，用于后续 DEM 曲面插值。

5. DEM 高程图构建

5.1 网格范围

elevation_plane.py 使用全部对齐点云的 X 和 Z 范围确定 DEM 覆盖范围， 并在两端增加 5% padding。viewer 数据接口中类似逻辑使用 2% padding。

5.2 规则网格

根据 grid_resolution 生成 N x N 的规则网格，默认 128 x 128。

xi = linspace(x_min, x_max, grid_resolution)
zi = linspace(z_min, z_max, grid_resolution)

5.3 散点插值

以地面候选点 G 的 (X, Z) 作为输入坐标，Y 作为高程值： 

elev_linear  = griddata(G[:, [0, 2]], G[:, 1], (xx, zz), method="linear")
elev_nearest = griddata(G[:, [0, 2]], G[:, 1], (xx, zz), method="nearest")
elev = where(isnan(elev_linear), elev_nearest, elev_linear)

linear 插值覆盖真实可插区域，空洞处用 nearest 补齐。viewer 返回的数据还带有 has_data，标记哪些格元来自线性插值的有效区域。

6. 网格与 GLB 输出

DEM 网格会被转换为三角 mesh。每个网格顶点坐标为：

vertex(i, j) = [X_j, elev(i, j), Z_i]

每个相邻四边形拆成两个三角面：

[i00, i10, i01] 和 [i10, i11, i01]

顶点颜色按高程归一化后映射到 matplotlib colormap。默认使用 terrain， 也支持 viridis、plasma、inferno、magma、 cividis、RdYlGn、coolwarm。

输出 文件名模式 说明
高程 mesh elev_r<N>_<cmap>_aligned_only.glb 只包含 DEM 曲面的 GLB。
合并场景 elev_r<N>_<cmap>_aligned_merged.glb 若传入原始 GLB，则把高程 mesh 叠加到点云场景上；否则与 only 文件相同。
元数据 elev_r<N>_<cmap>_aligned_meta.json 保存 gravity_source、n_grav、R_align、scale_factor、warning 和 debug。

7. 前端查看与体积

elevation_viewer.html 通过 POST /elevation_viewer_data 获取点云、对齐坐标、 DEM、相机轨迹和重力估计信息，用 Three.js 做交互式展示。

7.1 DEM 展示

viewer 会构建两套 DEM mesh：一套使用后端返回的 has_data 显示原始有效区域； 另一套对空洞进行最多 20 轮 8 邻域均值填充，用于更连续的可视化效果。

7.2 参考平面

前端参考平面主要用于视觉基准和 tooltip 高度零点。当前逻辑倾向于使用 DEM 中 has_data == false 的格元均值作为 refY_aligned，若没有空洞则 fallback 到网格中心高程。

7.3 选区体积

用户在屏幕上框选矩形、圆形或椭圆后，前端把屏幕选区反投影到地面水平面，再转换到 aligned 坐标的 (X,Z) 区域。体积使用 DEM 有效格元积分：

volume = sum((elev_cell - min_elev_in_region) * cell_area * scale_factor)

其中 cell_area 会乘以 scale_factor^2，高程差再乘一次 scale_factor， 因此总体按三次方尺度缩放。

8. 接口、参数与产物

8.1 拟合接口

接口 作用 核心参数
POST /fit_elevation 运行重力对齐、地面点筛选、DEM 插值、GLB 导出。 working_dir、source_glb_path、grid_resolution、colormap、ground_percentile、conf_thres、prediction_mode、scale_factor
POST /elevation_viewer_data 返回浏览器查看器所需的点云、DEM、相机、重力对齐矩阵。 working_dir、conf_thres、prediction_mode、ground_percentile
GET /viewer?session=... 跳转到静态 Three.js 高程查看器。 session

8.2 关键参数建议

参数 默认值 影响
grid_resolution 128 越高 DEM 越细，GLB 面数和计算成本越高。UI 范围是 32 到 512。
ground_percentile 20.0 无语义地面 mask 时，决定取最低多少百分位点作为地面候选。场景中目标物体多时可适当降低。
conf_thres 50.0 过滤低置信度点。拟合接口按最大置信度比例过滤；viewer 数据接口按百分位过滤。
scale_factor 1.0 绝对尺度校准系数。影响导出 mesh 尺寸和体积单位换算。

9. 当前实现注意点

  1. 地面语义 ID 被硬编码为 1。 elevation_plane.py 和 vggt_service.py 都使用 semantic_masks == 1 作为 ground mask。 如果 YOLOe 输出中 ground 不是 ID 1，则不会按预期使用语义地面。
  2. use_ransac 已不控制 DEM 拟合。 UI 仍显示 “Refine with RANSAC”，但后端 fit_elevation_to_glb 里实际 del use_ransac。 RANSAC 只在重力估计级联中使用。
  3. 后端导出 DEM 与 viewer DEM 有轻微差异。 拟合导出使用用户指定 grid_resolution 和 5% padding；viewer 数据接口固定 128 x 128 并使用 2% padding。
  4. 当前方案依赖重力对齐质量。 若相机轨迹退化、地面 mask 错误或点云大面积缺失，DEM 会出现倾斜、漂浮或高程基准错误。
  5. 体积基准不是 reference plane。 前端体积计算使用选区内 DEM 最低高程作为基准，不使用可视化参考平面。

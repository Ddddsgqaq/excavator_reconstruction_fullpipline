本周工作的核心，是在原有“上传数据后离线重建”的管线旁，增加一条可由真实相机驱动、可持续更新、并对结果质量负责的在线建图路径。

保持兼容

原有离线路径不变

视频/图像上传、YOLOe 分割、VGGT 重建、点云编辑和高程查看器均继续可用。

新增能力

实时滑窗重建

支持 USB、RTSP、HTTP/MJPEG 与视频源；关键帧筛选后按窗口触发 VGGT。

工程重点

可信的长期建图

通过会话状态机、质量门控、原子持久化和瓦片发布，避免低质量结果污染地图。

04新增改进：问题、实现与效果

改进 1：多源相机接入与实时性

用“最新帧覆盖”替代排队式消费

问题：VGGT 推理慢于相机帧率时，帧队列会不断堆积，最终重建的不是当前画面。

实现：camera_source.py 持续解码但只保留最新可用帧；支持 USB/V4L2、RTSP、HTTP/MJPEG，带目标 FPS 采样、超时、重连、凭据脱敏。source_factory.py 隔离不同输入源的创建逻辑。

效果：重建持续面向最新观测；可先进行仅取流健康检查，且兼容旧 video_path 协议。

改进 2：减少无效推理

关键帧缓存 + 滑动窗口调度

问题：相邻视频帧通常高度相似，重复执行 VGGT 会浪费 GPU。

实现：KeyframeBuffer 使用帧签名相似度，并可使用 ORB 特征；缓存受容量约束。ReconstructLoop 仅在关键帧数达到 min_frames 且窗口相对上次确有变化时执行，interval 控制节奏。

效果：算力随场景信息变化而非原始帧率消耗，可在时效性与算力间调节。

改进 3：坐标连续性

首帧锚定与局部地图配准

问题：不同局部窗口可能处于不同重建坐标系，直接拼接会导致 DEM 抖动或漂移。

实现：首轮建立并冻结 Anchor；后续 DemResult 先向基准地图注册。在线和离线共用重力对齐、地面筛选与 DEM 插值，统一“Y 即高程”的语义。

效果：局部观测进入稳定世界框架，变化具备可比较的位置和高度含义。

改进 4：从单次 DEM 到全局地图

GlobalDem 融合与瓦片化发布

问题：单窗口覆盖有限且噪声不稳定；下游也不应反复下载完整地图。

实现：GlobalDem 维护世界坐标下的全局栅格，并按融合配置更新；ElevationPublisher 输出增量 elevation Tile，流端点保留最近地形快照；pipeline.py 统一 DemResult 和消息格式。

效果：地图可逐步扩展，查看器和外部程序只接收变化数据。

改进 5：可信更新与可恢复性

两阶段 MapSession 与质量门控

问题：无条件融合会把误配准和瞬时噪声写入地图；服务重启也会丢失上下文。

实现：MapSession 持久保存版本化 manifest、锚点、参考帧、当前 DEM、全局 DEM；JSON / NPZ 均采用临时文件原子替换。初始化检查帧数、点数、覆盖率、高程跨度；增量检查 RMSE、覆盖率、变化面积和物理高度范围，并记录拒绝原因。

效果：只有合格且真正变化的结果才发布 Tile、推进版本；异常可审计、恢复或重新初始化。

改进 6：渐进式服务接入

不破坏原工作流

实现：实时能力封装在 streaming/。基础接口为 /stream/start、/stop、/status、/terrain；正式会话由 /stream/session/initialize、finalize、update、status 显式进入。orchestrator.py 增加实时面板。

效果：原 /reconstruct、/fit_elevation、YOLOe 与上传协议不变；可按“仅取流 → 滑窗验证 → 正式会话”逐步启用。

在线滑窗适合验证闭环；正式地图则由持久化 MapSession 管理，明确区分建基准和可信增量。

关键工程保障

  • 兼容性：新能力通过 /stream/session/* 显式启用，原有 /reconstruct、YOLOe、上传工作流不改协议。
  • 资源安全：在线与离线 VGGT 共享模型锁，避免并发 GPU 推理相互干扰。
  • 故障安全：会话 manifest、锚点与 DEM 原子写入，服务重启后可继续加载。
  • 可观测性：暴露连接、FPS、帧龄、重连和重建状态；支持仅取流诊断。
  • 测试：覆盖 MapSession、相机流和实时地形查看器等关键契约。

当前边界

已完成 CPU/兼容性与 API 契约验证；真实相机的长时 GPU 稳定性和各类现场阈值仍需结合实际尺度、运动方式与噪声进行标定。

06建议的组会讲述顺序

问题

离线重建无法持续反映现场变化，且单次结果缺少长期质量约束。

方案

以“实时滑窗 + 两阶段持久会话”连接相机输入、VGGT、DEM 融合与地图发布。

价值

既不破坏既有离线能力，又为可审查、可恢复、可对外消费的在线地形产品打下基础。

依据项目近一周的源码、测试、说明文档及生成产物整理。重点模块：streaming/、vggt_service.py、orchestrator.py、DEM 与实时查看器。
